El SHA remoto debe coincidir con `git rev-parse HEAD`. Si quedan commits locales
sin subir, usar `git push`; no recrear el repositorio ni forzar el push. No pegar
tokens ni contraseñas en chats ni guardarlos en el repositorio.

Preparación del M4 mañana
Requisitos: Git, Node.js 22.12 o posterior dentro de una versión admitida por
package.json y npm; Xcode/Command Line Tools para compilar la app macOS.
1. Autenticarse en GitHub con la cuenta indicada. Al ser privado, el clon requiere
   autorización; el navegador y Git pueden usar sesiones distintas.
2. Elegir una carpeta NUEVA, no sobrescribir la copia anterior del trabajo:
     git clone https://github.com/danieliiisimo22-bit/FORMA.git
     cd FORMA
3. Leer esta nota y el README. Instalar y arrancar:
     npm ci
     npm run dev
   Abrir la dirección local que muestre Vite, normalmente http://127.0.0.1:5173/.
4. Verificar y compilar:
     npm test
     npm run build
     npx playwright install chromium
     npm run test:e2e
5. Para una app nativa nueva en el M4:
     npm run build:macos
   Resultado: release/FORMA.app y ZIP universal. Es salida local y no se sube a Git.

Rutina al cambiar de Mac
ANTES de empezar:
  git status
  git pull --ff-only
Si hay cambios locales, guardarlos en un commit antes de actualizar; no usar
reset --hard ni sobrescribirlos para resolver una divergencia.

AL TERMINAR:
  git status
  git diff
  git add <archivos-revisados>
  git commit -m "Describe el cambio realizado"
  git push
Si cambia el estado de trabajo o aparecen pendientes, actualizar también esta
nota. Los archivos sin commit/push no viajan al otro equipo. No trabajar en la
misma rama desde los dos Mac simultáneamente; para trabajo paralelo usar ramas.
Si cambia package-lock.json, volver a ejecutar npm ci en el otro Mac.

Lo que Git NO sincroniza
La sesión, favoritos, paletas y recetas del usuario viven en almacenamiento
local del navegador/WebKit y dependen del equipo y del origen/puerto. Para llevar
las obras y ajustes editables: Mis recetas > Exportar biblioteca, guardar ese
JSON en un lugar personal y luego Importar JSON en el otro Mac. No subir por
defecto bibliotecas personales ni imágenes exportadas al repositorio de código.
La app compilada, dependencias y servidores locales tampoco se sincronizan.
